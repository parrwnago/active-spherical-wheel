# I-63 blind design advice, before new condition-feature arithmetic

This records review advice, not an executed experiment or the final root protocol. Previous I-60/I-61/I-62 outcomes are already known. No I-63 innovation/seam feature values, arithmetic outputs, or new label-conditioned outcomes have been read.

The authorized question is whether observable conditions explain when a fixed load-consistency tolerance is too strict or too permissive. A shared nonnegative affine threshold failed the earlier frozen-data screen. That does not prove that a causal condition-dependent threshold will fail, nor that a condition capable of separating the examples exists.

## Recommended scope

Keep this iteration an offline, retrospective diagnostic. There are only six harmful override frames, potentially fewer independent temporal events, and the +0.3 starting phase has no harmful baseline examples. Do not claim random-row cross-validation, unseen validation, reliable probability calibration, or readiness to change the live controller. Any adaptive follow-up should have its own source/protocol seal; a live or physics comparison requires a genuinely new episode after all offline gates pass.

## Suggested frozen signal

Use one combined score rather than select the better of components after observing outcomes. Each component may be reported descriptively.

1. Observer innovation: clip max absolute difference between interval-mean and filtered generalized residual rows 6:9, normalized by the existing 0.03 Nm + 0.10 R ||F|| engineering tolerance, to [0,1]. This is candidate independent, although derived from the same observer and not calibrated uncertainty.
2. Shell/belt seam risk: for both polar seams independently, form signed axial distance h = sign * axis(q) dot (-R n_raw) - shell_upper. Derive each rate by a strictly backward timestamp difference before taking a minimum across seams. Use clip(1 - min_j |h_j|/(0.012 m + 0.12 s * |h_dot_j|),0,1). The distance and horizon scales come from the existing incoming-drive preparation. Do not choose a seam using native support identity. Raw-normal motion and observer innovation may correlate; these are not independent sensors.
3. Combined risk is max(innovation, seam risk). Missing/invalid force, normal, timestamps or geometry produce unknown rather than a zero-risk or truth-derived fallback.

The interpretation is that rapid estimated wrench change or proximity/approach to a seam may require a larger tolerance, whereas stable geometry may permit a smaller tolerance. This is an unverified hypothesis. A large residual can also reflect model mismatch or a wrong contact; the score does not identify which.

## Preregistered qualification options for root to choose before arithmetic

Preferred scope is a transparent diagnostic. A fixed high-risk cutoff 0.5 can support a stringent plausibility screen: at least half of harmful overrides low risk, at least 90% useful corrections high risk pooled and in every phase; unknowns do not disappear from denominators. This would test that particular interpretation only, and is not a necessary condition for all adaptive rules. Counts must be accompanied by temporal event clusters and all accepted-wrong and predeclared point-outlier examples.

Alternatively, root can freeze a single bounded continuous threshold schedule before arithmetic and apply the existing fixed label-error, harmful-override, useful-retention, and point RMS/P95/max gates. This is a different primary analysis and must not be substituted after seeing which succeeds. No automatic controller promotion is recommended either way.

## Leakage and circularity controls

The source inputs are q, qdot, previous held belt input, observer wrench/generalized residual and interval mean, timestamps and fixed robot geometry. Native support shares are outputs of SupportLocator's own current assignment, so their apparent load transfer is not independent contact evidence. Native hardware-mode slip is rolling mismatch evaluated at the inferred point, not measured true slip. I-60 ranking margins and residual separation are already conditioned on the same geometry and no-slip model. Solver contacts, true slip, true force/normal/terrain, future frames, future winner persistence, and truth-stability windows are evaluation only. The prescribed previous belt input represents achieved belt speed only under the present ideal simulation model.

Report all six harmful overrides, 294 useful corrections, all 18 accepted-wrong frames, and any A point beyond the predeclared native maximum on the same fixed point mask. Include same-family point updates, not only family flips. Preserve unknown coverage and each phase separately. Do not tune component scales or choose smoothing windows from these outcomes.
