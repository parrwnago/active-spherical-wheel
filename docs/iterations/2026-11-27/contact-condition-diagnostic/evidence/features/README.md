# I-63 causal condition features

All three `stage01/CASE` artifacts were sealed before evaluation opened any
contact labels. Extraction read only timestamps, simulator pose, the observer's
filtered and last-interval generalized loads, and its raw inferred intrinsic
normal. A private kinematic model supplied the signed axes and fixed geometry
of the four known material patches. No contact query, physics step, terrain,
candidate identity or native support assignment was used. The registered risk
does not require qdot; the original hash-bound context retains q/qdot.

The primary seam coordinates are signed spherical surface arclengths to each
shell upper/belt lower boundary. Their derivatives use only the immediately
preceding valid 5 ms sample. First, missing or invalid predecessors make the
combined risk unknown. The scalar risk combines the frozen engineering scales
for joint filter innovation and distance/rate to a seam; it is not a calibrated
probability or a touchdown prediction. Axial distances and rates are retained
as diagnostics. The initial axial-primary proposal was superseded before any
historical arithmetic because axial distance compresses near the polar cap.

`primitives.npz` preserves the original cached axes and observer inputs;
`conditions.npz` contains 36 derived arrays. The thin NumPy-only replay uses
the frozen per-case helper source, recomputes every condition, and compares
array metadata and bytes without substituting stored results:

```sh
python3 features/feature_packets.py --features-root features/stage01 --output /tmp/i63_feature_replay
```

For the overall analysis wrapper, the API is
`load_and_derive_case(features_root, case) -> (conditions, parity)`. All 108
derived arrays match exactly on producer NumPy 1.26.4. The source was sealed
before that replay in `replay_source_stage01`, with its receipt in
`replay_producer_stage01`. The cached axes are not regenerated by portable
replay; doing that requires the original model and MuJoCo. Original primitive
files total 5,300,711 bytes. A proposed lossless XOR packer was written but never
executed; it was dropped when the original file size was accepted.

The 12 synthetic contracts cover prefix causality, unknown/gapped history,
normalization, seam and pole geometry, signed rates in both directions, world
frame rotation and private kinematics without physics/contact calls. Both
pre-execution logs contain the same inclusive 12 tests; they are not 24 tests.
