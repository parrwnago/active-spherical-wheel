# I-64 endpoint maps and matched load histories

The three native-controller logs were processed without new physics, contact
queries or controller changes. At each saved pose, private kinematics maps
world force into the three scalar generalized joint loads at the frozen I-61
proposal F, physical native alternative Nalt and virtual native equivalent Neq.
Neq is not projected onto a material patch. No new candidate is selected.

M0 uses current H times filtered force. M1 uses raw interval-mean force and raw
joint load. M2 filters raw predictions along the frozen accepted-proposal/native
fallback A path, then tests current F or Nalt from that common previous history.
M3 uses a separate Neq history as a sensitivity control. Current branch results
never rewrite either history. Force is filtered once. Endpoint H is held over
the preceding 5 ms interval; this is an approximation available at interval end,
not future contact prediction or known within-interval contact history.

Each history uses an observed joint-load seed once, then requires 200 ms of
contiguous valid inputs before scoring. Invalid committed paths, required loads
or time gaps break the chain. An invalid alternative does not break a valid
committed path. The full nine-channel observer control is reconstructed in the
original update order, separately from the force floor. Gap rows are unknown;
the following adjacent valid row starts an explicitly flagged new segment.
Initialization is not model agreement. The decomposition separates inherited
history error from the current raw-load residual. Its norm shares are descriptive
shares of two norms, not variance contributions, and are ill-conditioned near
zero terms.

All three `stage01/CASE` packets were sealed before evaluation read labels.
The 19 synthetic contracts pass, inclusive of the earlier 18. The extra
pre-execution contract checks segmented observer reconstruction across a gap;
the original histories are contiguous. Both tested source stages are retained.

`portable_stage01` retains original primitives, metadata and source plus exact
per-array bindings for all 228 derived arrays. The large canonical
`history_features.npz` files remain local and their omission is explicit. Replay
recomputes every array; it never substitutes the stored canonical values:

```sh
python3 features/history_packets.py check --package features/portable_stage01 --output /tmp/i64_feature_replay
```

The API is `load_and_derive_case(package, case) -> (derived, parity)`. Primitive
files total 9,966,155 bytes. The cached Jacobians are not regenerated by NumPy
replay; that requires the original model and MuJoCo.

Producer NumPy 1.26.4 reproduces all 228 arrays byte exactly. The first strict
NumPy 1.21.5 replay is preserved as a failure: 84 floating array hashes differ,
with measured differences at most 1.11e-16 Nm and 1.26e-12 in auxiliary norm
shares. All masks, integers, history ages and seeds are exact. The local
`compare_local_versions.py` diagnostic and `cross_version_diagnostic_stage01`
receipt retain per-field differences and raw witnesses. These differences were
not removed from computed values or hidden by altering scientific formulas.
Hash bindings alone report byte identity; they do not establish a numeric
tolerance without quantitative reference values.
