# I-61 independent review

The fixed extra-joint-load veto fails five of thirteen preregistered gates.
The independent audit reproduces the negative result; it is not a coding or
arithmetic discrepancy discovered by these checks. No threshold, score,
candidate, policy, observer, controller or feedforward was changed afterward.
The conditional physical comparison must not execute because the offline
screen fails.

## Primary result

All comparisons use the same 23,423 dominant-support eligible primary frames.
N is native. A is the I-60 accepted-proposal/native-fallback **pair** policy,
including same-family point changes. C applies the extra-three-row veto to
those same A proposals and otherwise returns the original native pair.

| Policy | Label disagreements | Point RMS, mm | Point maximum, mm |

| N | 412 | 3.134 | 26.908 |
| A | 124 | 2.757 | 29.843 |

The guard vetoes 46 of 6,902 proposals. Harmful native-correct overrides fall
only 6→5; useful corrections fall 294→264, a retention of 89.796%. The five
failed gates are harmful-override reduction, useful retention, pooled C-versus-A
label error, +0.3-rad C-versus-A label error and maximum point error versus N.
All three stable oracle-geometry compatibility gates pass above 99.35%, but
this is a fixed observed-force single-resultant compatibility test, not
independent generalized-force truth or calibrated sensor accuracy.

## What the failure narrows down

All thirty lost useful corrections lie outside the prespecified ±10 ms
stable-truth subset, and all thirty also fail the oracle-geometry load check
at those same frames. Stable-subset label errors are N75/A1/C1. Shaft residuals
exceed tolerance on forty of the forty-six vetoes; the two shell rows each
exceed it on six, with overlap. This is consistent with limitations of an
instantaneous single-resultant comparison during transfer, including filtering,
clock alignment or load distribution. It does not identify a unique cause.

At the retained bad 35.205 s sample, truth and native select belt B, while A/C
select shell B. Force magnitude is 18.421 N and the declared per-joint tolerance
is 0.2511 N m. Candidate residual magnitudes are 0.1727, 0.000002 and 0.1052 N m;
the maximum normalized ratio is only 0.688, so it passes. Oracle geometry also
passes. The check therefore does not separate the correct and wrong hypotheses
at its declared resolution. This is not an exactly zero-torque observation,
proof of delay alone, or evidence that a tighter threshold would fix the method.
The accepted point stays 29.843 mm from the equivalent reference versus
15.155 mm for native at that state.

First-three predicted force residuals vanish by construction because the same
observed force is supplied. Base moment repeats force-lever consistency, and
the common-shaft row largely projects the net moment. Added material-routing
information mainly comes from the shell rows, and can be weak near torque-null
configurations. Do not present nine independent contact measurements.

The one-resolved-contact subset still means only one record above 0.05 N;
weak contributors can remain in the load-weighted target. Current geometry,
last-completed-1-ms truth and the filtered preceding-5-ms observer remain
different quantities. This negative result rejects this frozen veto, not all
uses of generalized momentum information. Native LQR, momentum observer and
feedforward remain selected; I-60's shadow classification result and the lack
of demonstrated physical control improvement remain unchanged.
