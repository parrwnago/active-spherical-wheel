# I-61 independent blind design review

I-60 family/point results are known. No numerical comparison of the extra
three observer generalized-load rows against candidate point-force predictions
has been read for this review. The new experiment is an offline acceptance
check on frozen I-60 proposals, not a new controller or estimator rollout.

## Isolated intervention

Keep the I-60 bank, selected original candidate IDs, scores, confidence flags,
measured state, previous input and observer history fixed. Predict the nine
generalized external loads generated by the same observed net force at each
frozen selected point/body: gamma_candidate = J_point(q).T F_observed.
Do not fit another force, add a QP, rescore candidates, shift a point, smooth a
label or change the confidence gate. Report all nine rows, but use only the
three articulated-joint rows for the primary added-information veto.

A plausible preregistered engineering rule is componentwise
abs(gamma_observer[6:9]-gamma_candidate[6:9]) <= 0.03 N m + 0.10 R ||F||,
with all three components required. The floor is 5% of the existing small
joint's 0.6 N m cap; the relative term permits a force-lever discrepancy of
roughly 10% of radius. Those interpretations do not make it a calibrated
noise bound or guarantee validity of the single-resultant model. The parent
must freeze the actual rule before residual outcomes; these are recommendations.
Use an explicit invalid-input rejection and fallback, with component residuals,
maximum tolerance ratio and rejection reasons retained.

The common-shaft row is largely redundant in an instantaneous ideal model:
all wheel patches descend from that shaft, so shaft torque is its axis dotted
with the already-observed wheel-centre moment. The two shell rows can add
surface-routing information, since a carrier/belt force has zero shell-joint
load and a shell force loads only its own hinge. When that hinge-axis contact
torque is nearly zero, this information is unobservable. Do not claim all nine
rows are independent or that a small residual uniquely identifies contact.

## Frames, measurements and clock

MuJoCo point Jacobian transpose produces generalized loads conjugate to its
native velocity coordinates: free translation is world, free angular rows are
fork-frame, and the final three are scalar hinge torques. The observer stores
its first six rows in world axes. Rotate only the candidate base-angular rows
by fork rotation before comparison; do not rotate the last three.

The observer transforms each interval's first-six moment estimate with the
interval's mid rotation before world-frame filtering. The articulated rows are
filtered scalar coordinates. A current-configuration point Jacobian against
this filtered historical load is not an exactly synchronized instantaneous
force observation, especially during contact transfer or rapid rotation.
Primary/stable subsets and the last-1-ms truth versus preceding-5-ms observer
qualification from I-60 must remain explicit.

Observed force is fixed inference, not solver truth. Known applied torque is
already subtracted by the momentum observer; commands must not be substituted
for measured joint rates or added again as external force. Existing ideal-belt
surface actuation is part of the declared simulation model. No new physics,
contact-force query, terrain query, desired-speed input or future observation
belongs in the inference path.

## Policy and fair denominators

Define the unvetoed comparator as the frozen I-60 accepted-proposal policy with
native fallback, not all raw I-60 ranked labels. The new policy accepts that
same proposal only if the added-load check passes; otherwise it uses the exact
native family/point. State whether same-family accepted proposals can replace
the point: they can change geometry without a label override. Freeze that
choice before outcomes and retain explicit point/family source flags.

Count harmful overrides on states where native is correct, and useful
corrections where native is wrong and the I-60 proposal is correct. Suggested
meaningful screening: remove at least 50% of existing harmful accepted
overrides while retaining at least 80% of useful corrections. Also require
label nonregression relative to the unvetoed hybrid and superiority to native
on the same primary frames, with fixed per-phase allowances if used. Rejecting
everything must fail useful-retention/coverage gates. Empty denominators are
unscorable, not passes. These gates need parent adoption before residuals.

Evaluate family error and point mean/RMS/p95/max on identical full primary,
stable and fixed-event frames for native, unvetoed I-60 hybrid and vetoed hybrid.
Do not report only the retained set or compare its point errors with a different
baseline population. Report confidence/override coverage, native-correct point
degradation and remaining wrong-family tails, including all rejected outcomes.
No post-outcome threshold or subset search should replace the primary result.

## Model compatibility, not force calibration

After inference outputs are sealed, use fixed stable loaded truth segments to
describe native/candidate/oracle-geometry compatibility at the same threshold.
The saved I-58 truth includes normal-load shares and load-weighted points, not
per-contact full force vectors or independent nine-row generalized-force truth.
J(true dominant body, true patch mean).T F_observed is an oracle-geometry,
single-resultant check; it is not calibrated observer error. More than one
physical contact, tangential load distribution, other body force and filtering
can all violate that approximation. Broad rejection on these segments is a
model/clock-validity warning, not proof of widespread wrong contact.

The field counting one historical contact only counts records above 0.05 N.
Use “one resolved contact” and retain weak-contact ambiguity; neither the
90%-dominant-support primary mask nor the resolved-count subset proves exact
single physical contact.

## Controls and eventual independent audit

Before actual residual arithmetic, bind the new source, tests, protocol,
unchanged I-60 artifacts and recorded measurement hashes. Useful synthetic
contracts include nonidentity fork rotation, virtual-work frame invariance,
direct point-Jacobian prediction, shell-specific/inactive-joint routing,
force superposition, threshold boundary behavior, invalid-input fallback,
same-family point policy, and input/model nonmutation. A false candidate that
passes when contact torque vanishes demonstrates the identifiability limit.

After outputs are sealed, independently reproduce generalized-load predictions,
all component/tolerance decisions, native/unvetoed/vetoed policy selection,
harmful/useful confusion counts, matched point statistics, fixed windows and
every gate. Preserve model-validity failures and abstain-all behavior. Even a
passing offline check only supports a later controlled experiment; it does not
justify editing the live LQR, momentum observer or feedforward automatically.
